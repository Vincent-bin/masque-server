# Project provenance

MASQUE Server began as a fork of
[`Kotodian/masque-rs`](https://github.com/Kotodian/masque-rs), originally
authored by QianKaiLin. The upstream README identified the project as MIT
licensed.

The standalone repository retains the original Git commits and authorship.
Subsequent work added, among other changes, standard CONNECT support, proxy
authentication, bounded backpressure, multi-core sharding, Linux batched UDP
I/O and offloads, release packaging, deployment automation, and expanded E2E
and performance testing.

This notice records provenance; it does not imply endorsement by the original
author.
